## 書き方のルール

- Markdown で書く（GitHub 上でそのまま読める）
- 図は Mermaid で書く（GitHub がそのまま描画する）
- 実装を変えたら、関係するドキュメントも同じコミットで更新する
- パスはリポジトリ直下からの相対パスで書く（例: `dev/src/app/data/articles.ts`）
