# 画面設計書

[基本設計書](../02_基本設計書/基本設計書.md) の画面（Home / Tech / TechDetail / Diary / DiaryDetail / About）について、画面の構成・見た目・動きを定める。<br>
処理（記事の取得・階数・オープニングを出す条件など）は [処理設計書](処理設計書.md) を参照。

---

## 0. 本書について

### 0.1 位置づけ（リバースエンジニアリング）
本書は、**先に作った実装（`dev/` のソース）を読み解いて、設計書の形に書き起こしたもの**である（リバースエンジニアリング）。<br>
私に実装の経験がないため、AIと対話しながら実装を進め、完成したソースから逆算して記録した。

そのため、本書の各項目には次を併記する。

| 併記する内容 | 目的 |
|-------------|------|
| 対応する要件（F-01 など）・画面イメージ（IMG-01 など） | 要件定義書・基本設計書とのつながりを追えるようにする |
| 実装しているファイル | 変更したいときに、どこを見ればよいか分かるようにする |
| しくみの補足 | 実装経験がなくても、なぜそう動くのかを理解できるようにする |

設計書と実装が食い違った場合は、**実装（ソース）が正**とし、本書を実装に合わせて直す。

### 0.2 ソースの場所
画面に関するソースは `dev/src/` にある。以下、本書のパスは `dev/src/app/` からの相対パスで書く（例: `pages/Home.tsx`）。

| フォルダ | 中身 |
|---------|------|
| `pages/` | 画面 1 つ分の部品（Home・記事一覧・記事詳細・About・404） |
| `components/` | 複数の画面で使う部品（ヘッダー・フッター・記事カードなど） |
| `styles/global.css` | サイト全体の見た目（色・フォント・共通部品のスタイル） |
| `components/*.module.css` | 部品ごとの見た目（その部品の中だけに効く） |
| `App.tsx` | URL と画面の対応表 |
| `../public/` | そのまま配信する画像（ファビコン・顔のイラスト） |

### 0.3 用語
| 用語 | 意味 |
|------|------|
| コンポーネント（部品） | 画面の一部分を作る、React の部品。`Header.tsx` のように 1 ファイル 1 部品で作り、組み合わせて画面にする |
| props | 部品に外から渡す値。例: 記事カードに「どの記事か」を渡す |
| SPA | ページを移動しても HTML を読み直さず、ブラウザの中で画面を差し替える作り。移動が速い |
| CSS 変数 | `--pink` のように名前を付けた色などの値。1 か所変えると、使っている所がすべて変わる |
| CSS Modules | `Header.module.css` のように、その部品の中だけに効く CSS。ほかの部品のスタイルとぶつからない |
| SVG | 図形を数値で描く画像の形式。街並み・リムジンは画像ファイルではなく SVG のコードで描いている |
| アニメーション（CSS） | `@keyframes` で「何秒かけてどう変わるか」を書くと、ブラウザが自動で動かす |

## 2. デザインの方針

**にぎやかな未来都市「NEW HIROTO CITY」× ドット絵のゲーム画面**

基本設計書のとおり、MOTHER 3（原作・GBA 版）の「ニューポークシティ」から着想を得る。
作品の名前・キャラクター・ロゴなどの権利物は使わず、配色・レイアウト・装飾は独自に設計する。

- 背景はお店の床のような市松模様（薄いラベンダーグレーと藤色）
- Home は青い空と、ビル・タワー・観覧車・おもちゃのオブジェを詰め込んだ「ガチャガチャした」街並み
- 水色がかった白い通路と、その下のこげ茶の地層（オレンジの波線）
- ベタ塗りと紺の縁取り。影（右下にずらした影・立体的な縁取り）は付けない。角は少しだけ丸くする
- 見出しはゲームの戦闘メッセージ窓風。ゲームの会話ウィンドウ（◆ … ▼）、エレベーターの階数表示風の番号（1F, 2F, …）

| `--sky-top` / `--sky-bottom` | `#5f78cf` / `#a9bbee` | Home とオープニングの青い空 |
| `--frame` | `#2b3570` | 画面のふち |

| `--tower` / `--tower-dark` | `#34408a` / `#1d2452` | タワーの紺（ヘッダー、フッター、枠線、コードブロック） |
| `--earth` / `--earth-line` | `#5e3220` / `#e0883c` | 地層のこげ茶とオレンジの波線 |
| `--green` | `#7ee05a` | 選択中のナビ、ボタン、404 の看板 |
| `--pink` / `--pink-deep` | `#ff6fae` / `#c42f74` | DIARY の看板 / 明るい地の上のリンク |
| `--cyan` / `--teal-deep` | `#5ad6ea` / `#1f7c86` | TECH の看板、タワーの窓 / アクセント |

### 3.3 共通の部品（`styles/global.css`）

| クラス | 見た目 | 使う場所 |
|--------|-------|---------|
| `.sign`（+ `.sign-cyan` / `.sign-gold` / `.sign-green`） | ゲームの戦闘メッセージ窓風の看板。それぞれの色の地に紺の太い枠、内側に細い明るい線、右下に「▽」（上下に動く）。既定はピンク | 各画面の見出し（TECH・DIARY・ABOUT・404） |

| `.earth` | 通路のふち + こげ茶の地層とオレンジの波線 | ヘッダーの下、Home の下端、フッター |
| `.dialog` | ゲームの会話ウィンドウ（紺の地に白い枠）。最後の ▼ が上下に動く | Home |
| `.button`（+ `.button-ghost`） | 黄緑 / 通路色のボタン。ホバーで少し明るく、押すと少し暗く。▶ / ◀（`.button-arrow`）はホバー中に点滅する | 各所のボタン |

| `.prose` | 通路色のパネル（紺の枠） | About、記事の本文 |
| `.grid` | 記事カードの並び（横 3 つずつ） | Tech・Diary |
| `.page-lead` / `.status` | 床の柄の上に置く文字を、白い帯に載せて読みやすくする | 説明文、「まだ記事がありません」など |

## 4. 全画面共通のレイアウト

全画面、上から **Header → 画面本体 → Footer** の順に並ぶ（`components/Layout.tsx`）。

> **しくみの補足**: `Layout.tsx` は「枠」の部品で、真ん中の画面本体だけを URL に応じて差し替える（React Router の `<Outlet />`）。ヘッダーとフッターは画面を移動しても作り直さない。

### 4.1 Header（`components/Header.tsx` / `Header.module.css`）【F-01】
- 紺の帯。下に地層の帯
- 左: 顔のアイコン（`public/driver-face.png`、フチはカエルの緑）と金色の「SATO HIROTO」。押すと Home へ
- 右: ナビ（Home / Tech / Diary / About）。英字の上に日本語の小さなラベル（ホーム・技術・日記・自己紹介）
  - 今いる画面の項目は黄緑の札にする（記事の詳細では、親の Tech / Diary が選択中になる）
  - ホバーでピンクの文字
- 680px 以下では「☰」ボタンでナビを開閉する

### 4.2 Footer（`components/Footer.tsx` / `FrogParade.tsx`）
- カエルの行列: ファビコンのカエル（40px）を 100 匹並べ、画面の端から端まで埋める（はみ出した分は隠す）。奇数番目と偶数番目が交互に、よく見ると動いているくらい（1.5px）ゆっくり上下する。アイコンの白い背景は `mix-blend-mode: multiply` で帯の色になじませる
- 地層の帯
- 紺の帯に「END？」と ©

### 4.3 タブのタイトル（`components/Layout.tsx`）
「画面名　|　SatoHiroto」にする（例: `Home　|　SatoHiroto`）。TechDetail・DiaryDetail は親の画面名（`Tech　|　SatoHiroto`）。処理は [処理設計書の P-09](処理設計書.md#p-09-タブのタイトル)。

### 5.1 Home `/`（IMG-01）
| 項目 | 内容 |
|------|------|
| 対応する要件 | F-01（ナビ）、F-07（オープニング） |
| 実装ファイル | `pages/Home.tsx`、`components/Skyline.tsx`、`components/Splash.tsx` |

Home は「Welcome のブロック」だけにする。記事の一覧やボタンは置かない（Tech・Diary の専用画面と役割が重なるため）。各画面へはヘッダーのナビから移動する。

| ブロック | 内容 |
|---------|------|

| 「WELCOMEませ」の看板 | 紫の地に黄色の文字、黄緑と紺の市松模様の電飾の枠、マゼンタの脚 2 本。ときどき電気が消えたように暗くなる |
| 「NEW HIROTO CITYへ！」 | 金色の大きな文字に紺の縁取り |
| 会話ウィンドウ | 「◆こんにちは　ここでは　わたしがかいた　きじを　まとめています ▼」。▼ は上下に動く |
| 街並み | [6.2 街並み](#62-街並みskyline) |
| 通路と地層 | パネルの下端 |

サイトを Home から開いたとき（直接アクセス・再読み込み）だけ、最初にオープニング（[6.1](#61-オープニングsplash--limo)）を出す。

### 5.2 Tech `/tech`（IMG-02）・Diary `/diary`（IMG-04）
| 項目 | 内容 |
|------|------|
| 対応する要件 | F-01（ナビ）、F-02（記事の自動取得）、F-03（新しい順）、F-04（カードの内容） |
| 実装ファイル | `pages/ArticleListPage.tsx`、`components/PageHeader.tsx`、`components/ArticleList.tsx`、`components/ArticleCard.tsx` |

2 つの画面は同じ部品で作り、**同じ部品を同じ位置に並べる**。切り替えても小見出し・看板・説明文・電球・カードの位置がずれない（スクロールバーの有無による横ずれも `scrollbar-gutter: stable` で防ぐ）。画面全体を `.section-group` の枠で囲む。

| ブロック | Tech | Diary |
|---------|------|-------|
| 小見出し | ▶ 技術 | ▶ 日記 |
| 看板 | TECH（水色） | DIARY（ピンク） |
| 説明文 | ぎじゅつに　ついて　まとめています | にっきを　まとめています |
| 区切り | 電球の列 | 同じ |
| 記事一覧 | Qiita の記事（[5.3](#53-記事カードarticlecard)） | はてなブログの記事（最大 30 件） |
| リンク | 「Qiitaで読む ▶」（Qiita のマイページを別タブで開く） | 「はてなブログで読む ▶」（はてなブログを別タブで開く） |

記事一覧の並び（F-03）:
- **新しい順**（投稿日時の降順）に、左から右・上から下へ横 3 つずつ並べる（基本設計書の「3n+1 は n 段目」。1 番目・4 番目・7 番目…の記事が、各段の左端になる）
- 画面の幅が狭いときは横 2 つ（900px 以下）、横 1 つ（600px 以下）にする
- 記事がないときは「まだ記事がありません。」を出す（開発中に `dev/feeds.config.json` が未設定なら、設定方法を出す）

> **しくみの補足**: 文言と色は `data/articles.ts` の `SOURCE_PAGES` に書いてある。`ArticleListPage` は「qiita か hatena か」だけを受け取り、`SOURCE_PAGES` から文言を取り出して表示する。

### 5.3 記事カード（ArticleCard）
| 項目 | 内容 |
|------|------|
| 対応する要件 | F-04（タイトル・投稿日・タグ・いいねの数。本文は出さない） |
| 実装ファイル | `components/ArticleCard.tsx`、`components/ArticleCard.module.css` |

Tech・Diary で同じ見た目にする。

```
 ┌─────┐
 │ 1 F │ ← 階数表示（基本設計書の「ブログNo」。「F」だけ金色）
┌┴─────┴────────────────────┐
│ 2026.10.25　♡ 3            │ ← 投稿日（Qiita のみ ♡ いいねの数）
│ タイトル                    │
│ ───                         │ ← アクセント色の線
│            🐸               │ ← 本文のかわりのランダムな絵文字（Zenn 風）
│ [Ruby] [Rails]              │ ← タグ（はてなブログはカテゴリ）
│                     ▶ よむ  │
└────────────────────────────┘
```

| 部分 | 仕様 |
|------|------|
| 階数 | エレベーターの階数表示風に 1 文字ずつ箱に入れる。一番古い記事が 1F（決め方は [処理設計書の P-02](処理設計書.md#p-02-階数の付与)） |
| 投稿日・いいね | `2026.10.25　♡ 3`。いいね（Qiita の LGTM）ははてなブログにはないので出さない |
| タイトル | 日本語の見出しフォント。下にアクセント色の短い線 |
| 絵文字 | 本文（概要）のかわりに 1 つ大きく出す。20 種類から記事ごとに選ぶ（同じ記事はいつも同じ。[処理設計書の P-10](処理設計書.md#p-10-カードの絵文字)） |
| タグ | 枠付きの小さな札 |
| 見た目 | 通路色のパネル、紺の太枠、角丸。アクセント色（線・タグの枠）は並び順で 紺 → ピンク → こげ茶 → 青緑 を繰り返す |
| 動き | ホバーで少し明るくし、「▶ よむ」の ▶ を点滅させる。押すと TechDetail / DiaryDetail へ |

### 5.4 TechDetail `/tech/1F`（IMG-03）・DiaryDetail `/diary/1F`（IMG-05）
| 項目 | 内容 |
|------|------|
| 対応する要件 | F-05（サイト内の詳細ページで本文を読める。元の記事へのリンクも置く） |
| 実装ファイル | `pages/ArticleDetail.tsx`、`components/PageHeader.tsx` |

URL の「1F」は記事の階数。2 つの画面は同じ部品で作り、画面全体を `.section-group` の枠で囲む。

| ブロック | TechDetail | DiaryDetail |

| 区切り | 電球の列 | 同じ |

| タグ | タグの一覧 | カテゴリの一覧 |

存在しない階数（`/tech/99F`）や形式が違う URL（`/tech/abc`）の場合は 404 を表示する。

### 5.5 記事の本文のスタイル
| 項目 | 内容 |
|------|------|
| 実装ファイル | `styles/global.css` の `.article-body` 以下 |

Qiita・はてなブログが作った本文の HTML に、`.article-body` の中だけで効くスタイルを当てて、サイトのデザインにそろえる。

| 要素 | 見た目 |
|------|-------|
| 見出し（h1・h2） | 紺の札に白い文字（角丸） |
| 見出し（h3） | 先頭にピンクの「▶」、下に紺の線 |
| 見出し（h4〜h6） | 紺の文字 |
| 箇条書き・番号付きリスト | 字下げし、マーカー（・や番号）を紺に。入れ子は間隔を詰める |
| 強調（太字） | 文字の下半分に黄緑のマーカー |
| リンク | ピンク。外部リンクは別タブで開く |
| 引用 | 左に紺の太線、明るい通路色の地 |
| 区切り線 | 地層の柄（こげ茶にオレンジの波線） |
| 画像 | 紺の枠（角丸）で中央寄せ。読み込めない場合は「画像を表示できませんでした」 |
| 画像の説明（キャプション） | 画像の下に小さく中央寄せ |
| 表 | 見出し行は紺の地に白い文字、セルは明るい通路色。はみ出すときは横スクロール |

## 6. 共通の演出

### 6.1 オープニング（Splash / Limo）
| 項目 | 内容 |
|------|------|
| 対応する要件 | F-07 |
| 実装ファイル | `components/Splash.tsx`、`components/Limo.tsx`、`components/Splash.module.css` |

サイトを Home から開いたとき（直接アクセス・再読み込み）だけ、画面全体を青い空の幕で覆い、リムジンを走らせてから Home を見せる。出す条件は [処理設計書の P-08](処理設計書.md#p-08-オープニングの表示判定)。

| 時間 | 動き |
|------|------|
| 0〜3 秒 | リムジンが右の画面外から左の画面外まで、一定の速さで走り抜ける |
| 約 1.2〜1.45 秒（真ん中の少し手前） | 運転席（いちばん前の窓）から人が顔を出す（勢いよく出て少し戻る）。そのまま走り去る |
| 3〜3.4 秒 | 幕がフェードアウトして Home が現れる |

- リムジン: 紺の車体に金のライン、5 枚の窓、ピンクの小旗。タイヤは一定の速さで回り、車体が小さく揺れ、マフラーから煙が出る
- 顔: `public/driver-face.png` を円で切り抜き、カエルと同じ緑の丸いフチを付ける
- 下に道路と、点滅する「NOW LOADING」
- 幕を押すと、すぐに閉じる

> **しくみの補足**: 「顔を出す」動きは、顔の画像を車体の中（窓の下）から上へずらすアニメーションで作っている。窓の下端より下は見えないように切り取って（クリップ）いるので、車の中から顔が出てくるように見える。

スマホでは幅に合わせて左右が切れる。

### 6.3 アニメーション一覧
| 対象 | 動き | 実装 |
