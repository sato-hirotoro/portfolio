# 要件定義書（MyPortfolio）

## 1. 目的
自身がQiitaに書いた技術記事と、はてなブログに書いた日記を1つのサイトにまとめ、自分のデザインで読めるようにする。
- 記事そのものは外部サービス（Qiita・はてなブログ）で書く。このサイトは一覧と本文の表示を担う。
    - この2つのサービスは全文取得可能なAPI（またはフィード）が提供されていることを確認済。（2026.10.25時点）
- サーバー・データベース・認証を持たない静的サイトにし、GitHubPagesで公開する。（運用の手間と費用はかからない）

## 2. 利用者
| 利用者 | 内容 |
|--------|-----------|
| 閲覧者 | 技術記事・日記・自己紹介を見る。 |
| 管理者（本人） | それぞれのブログサイトで記事を書くだけでMyPortfolioに反映させる。 |

## 3. 機能要件
| ID | 要件 |
|----|------|
| F-01 | ヘッダーのナビゲーションでページ（Home / Tech / Diary / About）を遷移できる |
| F-02 | Tech は Qiita、Diary ははてなブログの記事を自動で取得して表示する |
| F-03 | 記事一覧は新しい順（日付の降順）で表示する |
| F-04 | 記事カードにはタイトル・投稿日・タグ・いいねの数を出す（本文は出さない） |
| F-05 | 記事カードを押下すると、サイト内の詳細ページで本文を読める。元の記事へのリンクも置く。 |
| F-06 | 新しい記事は、毎朝の自動ビルドでサイトに反映される。 |
| F-07 | サイトを Home から開いたとき、オープニングのアニメーションを出す。 |

## ４. 非機能要件
| 項目 | 要件 |
|------|------|
| ホスティング | GitHub Pages |
| ドメイン | 独自ドメイン（取得したい）（取得するまではGitHubPagesのデフォルト） |
| 記事の取得 | ビルド時に取得してサイトに埋め込む。 |
| 安全性 | 外部から取得した記事の HTML は、ビルド時にサニタイズしてから表示する。 |
| レスポンシブ | PC・タブレット・スマホに対応させる。 |
| 運用コスト | 無料（独自ドメインを使用する場合は費用かかる） |

## 5. 注意
- GitHubActionsの定期実行は、リポジトリに60日間更新がないと自動で止まる。
- はてなブログのフィードは最新 30 件までのため、MyPortfolioに出せるのは最新30件まで。
    - はてなブログのAPIは読み取りだけでなく書き込み等もできるため、表示するためだけに使用するにはリスクが大きいと判断した。
- 外部サービス（Qiita API・はてなブログのフィード）の仕様が変わると、記事を取得できなくなる可能性がある。

## 6. 今後の検討事項
- はてなブログの31件目以降の記事も表示したい、またはMyPortfolioからブログを編集したい場合は、はてなブログのAPIを使用する。
